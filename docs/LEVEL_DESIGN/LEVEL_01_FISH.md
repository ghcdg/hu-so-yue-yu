## 三、逐区详细设计

### 3.1 区1:打工——遇到老伯，一言不合就开追

**场景**:都市写字楼背景,打卡机、工位、电脑(全部伪图卡片)

**伪图卡片清单**:
- `打卡机.jpg`:路过触发音效
- `疲惫的打工人.gif`:文字滚动"加班到凌晨三点半...好累啊..."

**NPC**:老伯(`老伯.jpg`)，站在区1入口

**开场对话**(普通话):
1. 老伯:"小伙子,看你这样子,刚下班?"
2. 某人:"是啊大叔,天天加班,感觉自己像条咸鱼。"
3. 老伯:"咸鱼?前面就有一条,去看看吧。"

**子场景触发**:对话第3句结束时 → 自动切入 **ChaseScene 追捕小游戏**

```
┌─────────────────────────────────────────────┐
│  ChaseScene: 追捕老伯                         │
│                                               │
│  场景: 写字楼天台，多层阶梯平台                │
│  老伯( MovableNpc ): 在平台间逃跑              │
│  某人( Player ): 追! 碰到老伯即抓住            │
│                                               │
│  状态驱动卡片:                                 │
│    老伯卡片: "逃" / "跳" / "躲"               │
│    某人卡片: "追" / "跳" / "跑"               │
│                                               │
│  抓到后:                                       │
│    老伯:"好啦好啦,年轻人腿脚真快。"            │
│    老伯:"咸鱼就在前面,不过...先给你这个。"     │
│    老伯递出指引 → 子场景结束                    │
│  回传: unlockPath → 解锁区2入口                │
└─────────────────────────────────────────────┘
```

**ChaseScene 配置要点**:
- 世界尺寸: 800×600
- 平台: 5层阶梯块(左右交错)
- 老伯逃跑速度: 120, 巡逻路径沿平台
- 玩家起点: 左下角(200, 500)
- 老伯起点: 右上角(600, 200)
- 不限时,抓到即结束

**收集物**:金币(印"累"字)

**碎片关键词**:**打工** + **追捕体验**

**作用**:建立"打工→疲惫→咸鱼"的语义关联,同时通过追捕小游戏让玩家立刻进入紧张有趣的玩法,而不是干巴巴的对话。老伯的"逃跑"造成"这家伙肯定知道什么"的悬念。

### 3.2 区2:咸鱼(隐喻具象化 + 反向引导)

**场景**:天台晾衣绳,挂着几条咸鱼

**伪图卡片清单**:
- `挂着的咸鱼.gif`:文字滚动"我是咸鱼...我躺平中...别碰我..."
  - 状态绑定: idle → "别碰我...", 被踢前 → "你干嘛!?"

**反向引导机制**:
- 咸鱼显示"别碰我..." → 玩家出于反骨心理一定会碰
- 碰了之后:
  - 咸鱼弹开 → 滚动 → 撞破一面墙 → 露出隐藏区域
  - 隐藏区域内:`咸鱼的日记.gif` 文字滚动"今天又躺了一天,梦想是什么..."
  - 获得:隐藏金币 + 隐藏发现计数

**收集物**:印"咸"字的金币

**碎片关键词**:**咸鱼**

**作用**:咸鱼从抽象比喻变成具象物件,通过反向引导激发探索乐趣。

---

### 3.3 区3:疑问(打工=咸鱼?)

**场景**:一面墙,上面有涂鸦

**伪图卡片清单**:
- `墙壁涂鸦.jpg`:大字"打工 = 咸鱼 ?"
- `等号.jpg`:中间巨大等号,玩家可踩着跳(平台)
- `问号.jpg`:悬浮在上方,靠近抖动

**互动**:
- 玩家踩等号跳跃(平台功能)
- 靠近问号,问号抖动 + 显示"想想看?"

**碎片关键词**:**= ?**(打工是否等于咸鱼?)

**作用**:用视觉问号引发玩家思考,为后续"梦想"做铺垫。

---

### 3.4 区4:足球(世界转折 → 惊喜)

**场景**:街角出现一个破旧足球,微微发光

**伪图卡片清单**:
- `破旧足球.jpg`:高亮背景,靠近显示"按 E 踢一脚"

**惊喜三段式**（踢足球触发）:

| 阶段 | 内容 | 手法 |
|------|------|------|
| 铺垫 | 全局提示"高人即将出现..." | hint 卡片 + glow 动效,1.5s |
| 揭示 | 角色卡片`星爷.gif` 滚动"做人如果冇梦想,跟咸鱼有咩分别?" | 中央偏上,文字滚动 |
| 互动 | 星爷对话:"好一脚!咸鱼翻身,二段跳强化,去挑战吧!" | 对话卡片 + 给 Buff |

**Buff 获得**:咸鱼翻身 = 二段跳高度+30%

**碎片关键词**:**少林足球**

**作用**:引出《少林足球》世界,从现实困境转向功夫奇幻。获得 Buff 增强操作能力。

---

### 3.5 区5:寺庙(引出处所)

**场景**:远处出现寺庙剪影,近处有路标

**伪图卡片清单**:
- `少林寺.jpg`:背景远处大图
- `路标.jpg`:"少林寺 →"

**收集物**:印"功"字的金币(在山路平台上方,需要二段跳)

**碎片关键词**:**少林**

**作用**:把"少林"关键词植入,暗示"功夫/梦想"的联系。

---

### 3.6 区6:星爷NPC(点题"梦想" + 对话子场景)

**场景**:小广场,星爷NPC(`星爷.jpg`)站着

**对话子场景触发**:靠近星爷,按 E 对话 → 切入 **DialogueScene**

```
┌─────────────────────────────────────────────┐
│  DialogueScene: 星爷对话                       │
│                                               │
│  背景: 小广场夜景(伪图卡片 "小广场")            │
│  左侧: 某人立绘("某人.jpg")                    │
│  右侧: 星爷立绘("星爷.jpg")                    │
│                                               │
│  对话(普通话,留白处理):                        │
│  1. 星爷:"年轻人,我看你骨骼精奇,是个练武奇才。"│
│  2. 某人:"啊?我只是一个打工人。"               │
│  3. 星爷:"打工人也可以有梦想啊。"              │
│  4. 某人:"梦想?可是我觉得自己像条咸鱼..."     │
│  5. 星爷(意味深长):"咸鱼...梦想..."            │
│     (留白,不直接说出台词)                      │
│  6. 星爷:"前面有个挑战,你敢不敢试?"            │
│     选项:                                      │
│     A. "敢!我要证明咸鱼也能翻身!"              │
│     B. "我不确定...但我试试看。"               │
│     (无论选什么,星爷都鼓励,推进主线)            │
│                                               │
│  子场景结束 → 回传 advanceStory               │
└─────────────────────────────────────────────┘
```

**隐藏惊喜支线**(区6角落,需探索发现):
- 伪图卡片`破旧的足球鞋.jpg`:隐藏在平台上方
- 靠近显示"踢一脚?"
- 按 E → 蹦出钢铁腿(`钢铁腿.gif` 滚动"我踢波嘅时候,你哋仲着开裆裤!")
- 奖励:额外金币 + 隐藏发现计数

**碎片关键词**:**梦想**(但不说完整台词)

**作用**:通过对话子场景,给星爷和主角一个"面对面"的沉浸感,比之前"站在路边说话"更有电影感。留白让玩家自己拼。

---

### 3.7 区7:挑战(难度机制)

**场景**:垂直向上的砖块阶梯 + 移动平台

**提示卡片**:全局 hint 卡片"跳上去,找到答案"

**操作挑战**:
- 二段跳 + 精确跳跃
- 砖块会碎裂:`碎砖.gif` 文字滚动"我碎了..."
- 失败:掉落回区6,可重试,无惩罚

**收集物**:印"想"字的金币(在砖块3上方,挑战最高点)

**作用**:利用 Buff 强化操作,体验"掌握感"。获得最后一个汉字。

---

## 四、揭示平台（集齐汉字登台）

**场景**:顶部平台,发光的揭示标记

**登台门槛**:需集齐全部 5 个汉字金币(累/咸/功/梦/想)

**流程**:
1. 玩家踏上揭示平台
2. 金币不足 → Toast 提示"还需收集 X 个汉字才能登台!",不触发揭示
3. 金币足够 → 触发揭示:
   - 全屏揭示卡片显示:
     ```
     粤语:做人如果冇梦想,跟咸鱼有咩分别?
     粤拼:zou6 jan4 jyu4 gwo2 mou5 mung6 soeng2, gan1 haam4 jyu4 jau5 me1 faan1 bit6?
     释义:做人如果没有梦想,那跟咸鱼有什么分别?
     ```
   - 播放粤语发音
   - 此时玩家脑中所有碎片归位:打工 + 追捕 + 咸鱼 + 梦想 + 少林 → 恍然大悟
   - 老伯再次出现,祝贺主角

**设计意图**:集齐汉字才能登台,给收集系统赋予意义。每个金币是一个汉字,玩家在奔跑跳跃中不知不觉收集了整句粤语的所有关键词。
