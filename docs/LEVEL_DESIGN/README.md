## 设计原则(回顾)

1. **铺垫链思路**:玩家一路经历碎片,潜意识拼凑出目标金句,最后揭示归位(详见 [../DESIGN_PHILOSOPHY.md 原则3](../DESIGN_PHILOSOPHY.md))
2. **惊喜三段式**:铺垫→揭示→互动(详见 [../DESIGN_PHILOSOPHY.md 原则4](../DESIGN_PHILOSOPHY.md))
3. **反向引导**:负面提示激发探索,碰了必有反馈(详见 [../DESIGN_PHILOSOPHY.md 原则6](../DESIGN_PHILOSOPHY.md))
4. **对话全程普通话,粤语只在揭示时刻**(详见 [../DESIGN_PHILOSOPHY.md 第三节](../DESIGN_PHILOSOPHY.md))
5. **分层扩展**:通用部分 JSON 数据驱动,独特玩法/动画用关卡脚本(详见 [../DESIGN_PHILOSOPHY.md 第四节](../DESIGN_PHILOSOPHY.md))
