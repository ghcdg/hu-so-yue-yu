## 一、项目概述

**项目名称**:狐嗦学园(谐音"胡说粤语")

**产品形态**:网页版 2D 平台跳跃冒险游戏

**一句话描述**:操控小狐狸"某人"在各地跑跳闯关,经历一路的人物、物件、对话铺垫,最后触发一句金句——是一款真正好玩的游戏,只是恰好能学点粤语。

**核心理念**:**游戏第一,学习第二**。先做好玩的平台跳跃游戏,学习在玩家享受游戏的过程中自然发生。

## 二、目标用户

| 用户画像 | 场景 | 核心需求 |
|---------|------|---------|
| 想学粤语但不知从哪开始的人 | 通勤路上玩两关 | 低门槛接触粤语,不要学习压力 |
| 来广东旅游想用粤语点餐的人 | 旅游前练几句实用语 | 快速掌握衣食住行常用语 |
| 对粤语文化感兴趣的非母语者 | 无聊时当普通游戏玩 | 娱乐第一,学习是顺便 |
| 年轻一代粤语能力退化的广东人 | 日常碎片时间 | 重拾母语,但不想要"上课感" |

## 三、核心功能

### 3.1 平台跳跃闯关(核心玩法)
- A/D 左右移动,W/空格跳跃(支持二段跳),S 蹲下,E 互动
- Arcade 物理引擎:重力、平台碰撞、惯性
- 障碍物、移动平台、可碎砖块

### 3.2 铺垫链系统(核心创新)
- 关卡由多个区域组成,每个区域铺一个"碎片"(人物/物件/对话)
- 玩家一路经历碎片,潜意识拼凑出目标金句的轮廓
- 最后通过难度挑战完成,触发句子揭示,所有碎片归位产生"恍然大悟"爽感

### 3.3 惊喜三段式叙事(核心创新)
- 不是"蹦出角色说台词",而是有节奏的三段式:铺垫 → 揭示 → 互动
- 惊喜来源:文化梗 / 网络热梗 / 谐音梗 / 粤语本地文化符号
- 互动转化为玩法收益(指引 / buff / 解锁)

### 3.4 伪图卡片系统(核心创新)
- 用"框 + 文字"代替真实图片,`.jpg` 静态 / `.gif` 文字循环滚动
- 全局复用:场景物件 / 角色立绘 / 对话卡片 / 提示卡片 / 结算卡片
- 后期可无缝替换真图,现阶段省去美术工作量

### 3.5 发音引擎
- 当前方案:Jyutping 粤拼合成(基于粤拼音素映射 + Web Audio API,零依赖离线可用)
- 策略模式预留:Web Speech API / 豆包 TTS API 接口

### 3.6 收集与成就
- 金币(印着粤语词,拾取触发发音)
- 隐藏惊喜发现计数
- 通关评价(咸鱼翻身 / 咸鱼之王 / 梦想家)

## 四、技术架构

### 4.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| UI 外壳层 | Vue 3 + Vite + TypeScript + Pinia | 菜单/地图/图鉴/设置等非游戏内 UI |
| 游戏渲染层 | Phaser 3 | 平台跳跃游戏引擎,内置 Arcade 物理 |
| 发音引擎 | JyutpingSpeaker(当前) | 策略模式预留 Web Speech / 豆包 TTS |
| 开发工具 | TRAE IDE | 全程 AI 辅助开发 |

### 4.2 分层原则
- `ui/` 层不碰游戏逻辑,只管菜单/图鉴/全局弹窗
- `game/` 层自包含,Phaser 场景内部自治
- 两层通过 Pinia store 共享进度状态,通过事件总线通信
- 核心组件(TextSprite/Speaker/Player 等)设计时预留扩展点,但不过度抽象;每关可自由定制文件/脚本。详见 [DESIGN_PHILOSOPHY.md 第四节](./DESIGN_PHILOSOPHY.md)。

详细架构见 [TECH_ARCH.md](./TECH_ARCH.md)。

## 六、初赛评分对标

| 维度 | 权重 | 应对策略 |
|------|------|---------|
| 创新性 | 30% | 铺垫链思路 + 惊喜三段式 + 伪图卡片系统 + 游戏第一理念 |
| 实用性 | 30% | 真实金句 + 高可玩性 + 降低开口门槛 |
| 完成度 | 20% | 单关全链路跑通:移动→铺垫→惊喜→挑战→揭示→发音→结算 |
| 美观度 | 20% | 伪图卡片形式新奇有趣 + 流畅反馈动效(注:现阶段不追求精美,追求流畅) |
